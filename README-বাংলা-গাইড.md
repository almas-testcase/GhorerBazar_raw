# 🌿 খাঁটিঘর — ই-কমার্স সাইট (সম্পূর্ণ গাইড)

HTML + CSS + JavaScript দিয়ে বানানো, কিন্তু কাজ করে একটি পূর্ণাঙ্গ ফুলস্ট্যাক ই-কমার্সের মতো:
**ফ্রন্টএন্ড** (GitHub Pages) + **ব্যাকএন্ড** (Google Apps Script) + **ডাটাবেজ** (Google Sheet) + **অ্যাডমিন প্যানেল**। হোস্টিং/সার্ভার খরচ নেই।

## ✨ কী কী আছে
| ক্রেতার দিকে | অ্যাডমিনের দিকে |
|---|---|
| হোমপেজ স্লাইডার (অটো, সোয়াইপ, ছবিসহ) | ড্যাশবোর্ড: ৭ দিনের বিক্রির চার্ট, সেরা পণ্য, অর্ডারের অবস্থা |
| ক্যাটাগরি, ফিল্টার, সার্চ, সর্ট, ৪★+ রেটিং | অর্ডার ম্যানেজমেন্ট (স্ট্যাটাস, ইনভয়েস প্রিন্ট, CSV, WhatsApp) |
| কার্ট, কার্ডেই `− ১ +` স্টেপার, কুইক-ভিউ | পণ্য/স্টক/দাম/ছবি আপলোড, কুপন |
| কুপন, ফ্রি-ডেলিভারি প্রোগ্রেস, সাশ্রয় দেখানো | 🖼️ স্লাইডার ম্যানেজার (ছবি আপলোড, ক্রম, চালু/বন্ধ) |
| COD / বিকাশ / নগদ, অর্ডার ট্র্যাকিং | রিভিউ অনুমোদন, নোটিফিকেশন (ইমেইল/SMS) |
| ভেরিফাইড রিভিউ ও রেটিং | সেটিংস (ডেলিভারি, নম্বর, Meta Pixel ID) |
| মোবাইল বটম নেভ, WhatsApp বাটন, PWA, SEO | পাসওয়ার্ড সুরক্ষিত |

## 📁 ফাইল পরিচিতি
```
index.html            ক্রেতার দোকান
style.css             ডিজাইন সিস্টেম (রং/স্পেসিং ওপরের :root এ)
script.js             দোকানের লজিক
config.js             ★ এখানে Web App URL (ও ঐচ্ছিক Pixel ID/স্লাইড) বসাবেন
admin.html/.css/.js   অ্যাডমিন প্যানেল (পাসওয়ার্ড দিয়ে)
google-apps-script.gs ব্যাকএন্ড কোড (Google Sheet এ বসবে)
privacy.html terms.html 404.html   আইনি ও ৪০৪ পেজ
manifest.webmanifest sw.js icons/ favicon.svg   অ্যাপের মতো ইনস্টল + অফলাইন সহায়তা
robots.txt sitemap.xml   সার্চ ইঞ্জিনের জন্য
images/               নিজের ছবি (মাপের তালিকা ভেতরে README.txt এ)
.nojekyll             GitHub Pages এর জন্য
```

# ১) ব্যাকএন্ড বসানো (একবারের কাজ)

1. https://sheets.google.com এ নতুন খালি শিট খুলুন → নাম দিন "Khatighor Shop"।
2. **Extensions → Apps Script** → পুরনো কোড মুছে `google-apps-script.gs` এর পুরো কোড পেস্ট → Save।
3. উপরের ড্রপডাউন থেকে **setup** বেছে **Run**। অনুমতি চাইলে **Allow** (শিট, ইমেইল, Drive ও বাইরের URL এর অনুমতি লাগে)।
   → `Products, Orders, Coupons, Reviews, Slides, Settings` ট্যাব ও নমুনা ডেটা তৈরি হবে।
4. ⚙️ **Project Settings → Script Properties** → `ADMIN_PASSWORD` এর মান **নিজের শক্ত পাসওয়ার্ড** করুন (ডিফল্ট `changeme123` অবশ্যই বদলান)।
5. **Deploy → New deployment → Web app** → Execute as: **Me**, Who has access: **Anyone** → Deploy → **Web app URL** কপি।
6. `config.js` খুলে `SITE_API_URL` এ সেই URL বসান।

> কোড আপডেট করলে: কোড পেস্ট → `setup` আবার Run (নিরাপদ, ডেটা মোছে না) → **Deploy → Manage deployments → ✏️ → New version → Deploy** (URL একই থাকে)।

## পরীক্ষা
- `index.html` খুলে একটি টেস্ট অর্ডার দিন → `admin.html` এ লগইন করে দেখুন।
- অর্ডার ট্র্যাকিং সেকশনে অর্ডার আইডি + ফোন দিয়ে খুঁজুন।

# ১.৫) ⚙️ অ্যাডমিন → সেটিংস থেকে যা যা সাজাবেন (কোড/HTML ছোঁয়া লাগে না)

সাইটে **কোনো নমুনা/ভুয়া লেখা দেখানো হয় না** — তথ্য না দিলে সংশ্লিষ্ট অংশ নিজে লুকিয়ে থাকে:

| সেটিং | ফাঁকা রাখলে কী হয় |
|---|---|
| ইমেইল, ঠিকানা, খোলার সময় | ফুটারে ওই সারি দেখায় না |
| ফেসবুক / লিংকডইন / টিকটক লিংক | ফুটারে ওই আইকন দেখায় না। দিলে আসল ব্র্যান্ড আইকন (নতুন ট্যাবে খোলে)। শুধু `https://` লিংক গ্রহণযোগ্য। ব্যাকএন্ড ছাড়া চাইলে `config.js` এর `SITE_SOCIAL` এ দিন |
| হিরোর পাশে **কুপন কার্ড** (কুপন কোড) | কার্ডটি লুকানো থাকে। দিলে ক্রেতা চাপলে কোড কপি হয় ও চেকআউটের কুপন ঘরে বসে যায় |
| **অফার শেষের সময়** + লেখা (কাউন্টডাউন) | ব্যান্ড লুকানো। শুধু ভবিষ্যতের সময় দিলে দেখায়, সময় পেরোলে নিজে সরে যায় (নকল/চিরস্থায়ী কাউন্টডাউন নেই) |
| স্ক্রলিং নোটিশ | শুধু ডিফল্ট বার্তা ঘোরে |
| হোমপেজের **ক্রেতাদের মতামত** | **আসল** অনুমোদিত ৪★+ রিভিউ (লেখা ≥ ১৫ অক্ষর) থেকে নিজে আসে; একটিও না থাকলে সেকশনটিই দেখায় না |

> ডেলিভারি চার্জ, ফ্রি-ডেলিভারি সীমা, ফোন/WhatsApp/বিকাশ/নগদ নম্বর, Meta Pixel ID-ও একই পাতায়।

## ফিল্টার, চেকআউট ও উপরে-যাওয়া বাটন
- **ফিল্টার:** ডেস্কটপে সাইডবারে গুটানো যায় এমন ৩টি সেকশন (ক্যাটাগরি, দামের পরিসীমা, অবস্থা ও রেটিং), সক্রিয় ফিল্টারের সংখ্যা ব্যাজ; মোবাইলে নিচ থেকে ওঠা শিট, নিচের বাটনে লেখা থাকে "কয়টি পণ্য দেখুন"।
- **চেকআউট:** ডেস্কটপে দুই কলাম — বাঁয়ে **ডেলিভারির ঠিকানা ও পেমেন্ট পদ্ধতি**, ডানে (স্টিকি) **অর্ডার সামারি: পণ্য, কুপন, ডেলিভারি চার্জ, সর্বমোট ও কনফার্ম বাটন**। ট্যাবলেট/মোবাইলে একটির নিচে আরেকটি।
- **উপরে যাওয়ার বাটন:** ৬০০px স্ক্রলের পর WhatsApp বাটনের ঠিক উপরে আসে; গোল রিং দেখায় পেজের কতটা নামা হয়েছে; চাপলে মসৃণভাবে উপরে যায়।

## ❤️ পছন্দের তালিকা (Wishlist) ও 🌙 ডার্ক মোড
- **পছন্দের তালিকা:** প্রতিটি পণ্যের ছবির ডান-নিচে ❤️ চাপলে তালিকায় যায়। হেডারের ❤️ (মোবাইলে নিচের "পছন্দ") চাপলে ড্রয়ার খোলে — সেখান থেকে একটি/সবগুলো কার্টে দেওয়া বা সরানো যায়। কুইক-ভিউ পপ-আপেও "পছন্দের তালিকায় রাখুন" আছে।
  তালিকা ক্রেতার নিজের ব্রাউজারে সংরক্ষিত থাকে (লগইন লাগে না; এক ডিভাইসের ট্যাবগুলোর মধ্যে সিঙ্ক হয়)। অ্যাডমিন থেকে মুছে ফেলা পণ্য নিজে বাদ পড়ে। Meta Pixel এ `AddToWishlist` ইভেন্ট যায়।
- **ডার্ক মোড:** হেডারের 🌙/☀️ বাটনে বদলায়। ক্রেতা বেছে না নিলে তার ডিভাইসের সেটিং (সিস্টেম ডার্ক/লাইট) অনুসরণ করে; বেছে নিলে সেটাই মনে রাখে। পেজ খোলার সময় ঝিলিক (flash) হয় না (`theme.js`)। সব রং `style.css` এর `:root` (লাইট) ও `html[data-theme="dark"]` (ডার্ক) টোকেনে — রং বদলাতে শুধু ওখানে হাত দিন। কনট্রাস্ট দুই থিমেই ≥ ৪.৫:১ যাচাই করা। অ্যাডমিন প্যানেল সবসময় লাইট।

# ২) 🖼️ হোমপেজ স্লাইডার ও ছবির সঠিক মাপ

হোমপেজে সর্বোচ্চ **৫টি** স্লাইড (৩টি রাখাই ভালো)। ছবি দিলে ছবির স্লাইড, না দিলে রঙিন ডিজাইন করা স্লাইড দেখায়।

## সব ডিভাইসে মানানসই মাপ (এগুলো মেনে চলুন)

| কোথায় | মাপ (px) | অনুপাত | ফাইল সাইজ |
|---|---|---|---|
| **ডেস্কটপ ও ট্যাবলেট স্লাইড** | **1600 × 800** | 2 : 1 | ≤ 250 KB |
| **মোবাইল স্লাইড** (≤ 560px স্ক্রিন) | **1000 × 800** | 5 : 4 | ≤ 150 KB |
| পণ্যের ছবি | **800 × 800** | 1 : 1 | ≤ 120 KB |
| শেয়ার প্রিভিউ `images/og.jpg` | 1200 × 630 | ≈ 1.9 : 1 | ≤ 200 KB |

**কেন এই মাপ:** স্লাইডার স্ক্রিন অনুযায়ী অনুপাত বদলায় — ডেস্কটপে 2:1, ট্যাবলেটে ≈ 21:9 বা 16:9, মোবাইলে 5:4। ছবি `cover` হয়ে বসে, তাই ছোট স্ক্রিনে কিনারা সামান্য কাটা পড়ে।
📌 **নিরাপদ এলাকা:** লেখা, লোগো বা মূল পণ্য ছবির **মাঝের ৮৫%** এলাকায় রাখুন (প্রতিটি কিনারা থেকে অন্তত ৮% ভেতরে)।
💡 শুধু একটি (ডেস্কটপ) ছবি দিলেও চলবে — মোবাইলে সেটাই কাটছাঁট হয়ে দেখাবে। তবে মোবাইলে সেরা ফল পেতে আলাদা 1000×800 ছবি দিন।
💡 ছবি ছোট করতে: squoosh.app বা tinypng.com। ফরম্যাট JPG/WebP।

## ছবি বসানোর ৩টি উপায়

**উপায় ১ — অ্যাডমিন প্যানেল থেকে (সবচেয়ে সহজ, সুপারিশকৃত)**
`admin.html` → **🖼️ স্লাইডার** → ➕ নতুন স্লাইড / ✏️ এডিট → "⬆️ আপলোড" চাপুন → ছবি বাছুন।
ছবি **নিজে থেকে সঠিক মাপে কেটে ছোট করে** Google Drive এ জমা হয় এবং লিংক বসে যায়। ⬆️⬇️ দিয়ে ক্রম বদলান, চালু/বন্ধ করুন। সাইটে সাথে সাথে বদলায় (কোড/GitHub ছোঁয়া লাগে না)।

**উপায় ২ — নিজের ছবির লিংক দিয়ে:** স্লাইড এডিটে "ছবির ঠিকানা" ঘরে যেকোনো `https://...` ছবির লিংক পেস্ট করুন।

**উপায় ৩ — ব্যাকএন্ড ছাড়া, ফাইল দিয়ে:** ছবি `images/` ফোল্ডারে রেখে `config.js` এ লিখুন:
```js
const SITE_SLIDES = [
  { imgDesktop: "images/slide1.jpg", imgMobile: "images/slide1-m.jpg", link: "#products" },
  { imgDesktop: "images/slide2.jpg", imgMobile: "images/slide2-m.jpg", title: "ঈদ অফার", subtitle: "সব পণ্যে ১০% ছাড়", btnText: "কিনুন", link: "#products" },
];
```
অগ্রাধিকার: অ্যাডমিনের স্লাইড → `config.js` → ডিফল্ট ডিজাইন।

**স্লাইডের লেখা:** ছবিতে লেখা বেক করা থাকলে শিরোনাম/উপশিরোনাম ফাঁকা রাখুন (শুধু ছবি + ক্লিকযোগ্য লিংক)। লেখা যোগ করলে ছবির বাঁ-পাশে গাঢ় ছায়ার ওপর সাদা লেখা বসে।

**আচরণ:** ৫.৫ সেকেন্ড পরপর অটো-চলে (প্রগ্রেস বার সহ), আঙুল/মাউস দিয়ে টেনে সোয়াইপ, মাউস রাখলে/ট্যাব লুকালে/স্ক্রিনের বাইরে গেলে থামে, শেষ থেকে প্রথমে নরম ফেড। "কম মোশন" সেটিং চালু থাকলে অটো-প্লে বন্ধ।

# ৩) 🔔 নোটিফিকেশন (ইমেইল ও SMS)

অ্যাডমিন → **🔔 নোটিফিকেশন**:
- **ইমেইল:** "নতুন অর্ডারে আমাকে ইমেইল" ✔ + ইমেইল দিন → 💾 সংরক্ষণ → **✉️ টেস্ট ইমেইল**। ক্রেতা ইমেইল দিলে তাকেও কনফার্মেশন যায়। (Gmail এ দিনে ≈ ১০০টি)
- **SMS:** যেকোনো SMS গেটওয়ে (BulkSMSBD, GreenWeb ইত্যাদি) থেকে API Key নিন → প্রিসেট বা নিজের URL টেমপ্লেট দিন → API Key, Sender ID, আপনার নম্বর → সংরক্ষণ → **📱 টেস্ট SMS**।
  টেমপ্লেটের চিহ্ন: `{key}` `{sender}` `{number}` (8801…) `{number_local}` (01…) `{message}`।
  > প্রিসেটের URL গেটওয়ের বর্তমান ডকুমেন্টেশনের সাথে একবার মিলিয়ে নিন।
- **কখন কী যায়:** নতুন অর্ডার → আপনাকে + ক্রেতাকে। স্ট্যাটাস কনফার্মড/শিপড/ডেলিভারড/বাতিল → ক্রেতাকে।
- API Key শুধু Apps Script এর গোপন Properties এ থাকে, সাইটে/শিটে প্রকাশ পায় না। নোটিফিকেশন ব্যর্থ হলেও অর্ডার আটকে না (কারণ: Apps Script → Executions)।

# ৪) ⭐ রিভিউ ও রেটিং
- শুধু **ডেলিভারড** অর্ডারের ক্রেতা রিভিউ দিতে পারেন (অর্ডার আইডি + ফোন মিলতে হবে, এক অর্ডারে এক পণ্যে একটি) → "✔ ভেরিফাইড ক্রেতা" ব্যাজ।
- রিভিউ প্রথমে "অপেক্ষায়" থাকে; অ্যাডমিন → **⭐ রিভিউ** → ✅ অনুমোদন দিলে সাইটে দেখায়। নিজেও রিভিউ যোগ করা যায়।
- ক্রেতার শুধু নামের প্রথম অংশ প্রকাশ পায়।
- অনুমোদিত ৪★+ রিভিউ হোমপেজের "ক্রেতাদের মতামত" সেকশনেও নিজে থেকে আসে।

# ৫) 📈 Meta (Facebook) Pixel — শুধু ID বসালেই চালু
**ID:** Facebook Events Manager → Data Sources → আপনার Pixel → ID (১৫-১৬ ডিজিট)।
- 🅰️ **অ্যাডমিন → ⚙️ সেটিংস → "Meta Pixel ID"** (যেকোনো সময়, কোড না ছুঁয়ে। ফাঁকা করলে বন্ধ)
- 🅱️ অথবা `config.js` → `SITE_PIXEL_ID = "আইডি"` (অ্যাডমিনেরটা অগ্রাধিকার পায়)

ইভেন্ট: PageView, ViewContent, AddToCart, Search, InitiateCheckout, Purchase (`eventID` = অর্ডার আইডি), Contact। যাচাই: Chrome এ **Meta Pixel Helper** বা Events Manager → Test Events। "Do Not Track" চালু থাকলে Pixel চলে না।

# ৬) 🚀 GitHub Pages এ লাইভ করা (ধাপে ধাপে)

## ক) আপলোড
1. https://github.com এ অ্যাকাউন্ট খুলুন → **New repository** → নাম দিন (যেমন `khatighor`) → **Public** → Create।
2. টার্মিনালে প্রজেক্ট ফোল্ডারে (`D:\L1\grocery-landing`):
```bash
git init
git add .
git commit -m "খাঁটিঘর ই-কমার্স সাইট"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/khatighor.git
git push -u origin main
```
   (অথবা GitHub এর "uploading an existing file" দিয়ে সব ফাইল ড্র্যাগ-ড্রপ করুন — ফোল্ডারসহ, `.nojekyll` ফাইলটি ভুলবেন না।)
3. রিপোতে **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `(root)` → Save**।
4. ১-২ মিনিট পর সাইট লাইভ: `https://YOUR-USERNAME.github.io/khatighor/`

## খ) লাইভ হওয়ার পর একবার ঠিক করুন
| ফাইল | কী বদলাবেন |
|---|---|
| `config.js` | `SITE_API_URL` = Web App URL (ধাপ ১ এর) |
| `index.html` | `og:image` এ `https://YOUR-USERNAME.github.io/khatighor/images/og.jpg` বসান (শেয়ার প্রিভিউয়ের ছবি) |
| `robots.txt`, `sitemap.xml` | `YOUR-USERNAME` ও `YOUR-REPO` নিজের মান দিয়ে বদলান |
| অ্যাডমিন | পণ্য, দাম, স্লাইড, এবং সেটিংসে নম্বর/ইমেইল/ঠিকানা/ফেসবুক/অফার ঠিক করুন |

## গ) নিজের ডোমেইন (ঐচ্ছিক)
ডোমেইন কিনে DNS এ GitHub Pages এর রেকর্ড দিন → রিপো **Settings → Pages → Custom domain** → ডোমেইন লিখুন → **Enforce HTTPS** ✔। তখন `robots.txt`/`sitemap.xml`/`og:image` এর লিংক নতুন ডোমেইনে বদলে নিন।

## ঘ) সাইট আপডেট করার নিয়ম
ফাইল বদলে `git add . && git commit -m "আপডেট" && git push` — ১-২ মিনিটে লাইভ। (সার্ভিস ওয়ার্কার "নেটওয়ার্ক-ফার্স্ট", তাই ক্রেতারা পুরনো কপিতে আটকে থাকে না।)
পণ্য/স্লাইড/সেটিংস/কুপন বদলাতে **GitHub লাগে না** — অ্যাডমিন প্যানেল থেকেই হয়।

## ঙ) নিরাপত্তা নোট (গুরুত্বপূর্ণ)
- রিপো Public হলে `google-apps-script.gs` সবাই দেখতে পারবে — তাতে কোনো পাসওয়ার্ড/কী নেই (সব Script Properties এ), তাই নিরাপদ।
- `admin.html` এর ঠিকানা কাউকে দেবেন না; শক্ত `ADMIN_PASSWORD` ব্যবহার করুন। পাতাটি `noindex` ও `robots.txt` এ বাদ দেওয়া।
- দাম ও স্টক সবসময় সার্ভারে যাচাই হয়, ব্রাউজারে বদলে লাভ নেই। ডুপ্লিকেট/স্পাম অর্ডার আটকানো আছে।
- `uploadImage` শুধু অ্যাডমিন পাসওয়ার্ড দিলে চলে, এবং শুধু JPG/PNG/WebP (ম্যাজিক-বাইট যাচাই) নেয়।

# ৭) 🛠️ সমস্যা হলে
| সমস্যা | সমাধান |
|---|---|
| পণ্য আসছে না / শুধু নমুনা পণ্য | `config.js` এ Web App URL ঠিক আছে? Deploy এ "Anyone" দেওয়া? |
| অ্যাডমিনে "পাসওয়ার্ড ভুল" | Script Properties এ `ADMIN_PASSWORD` মিলিয়ে দেখুন |
| নতুন ফিচার কাজ করছে না | নতুন `.gs` পেস্ট → `setup` Run → **New version** Deploy |
| ছবি আপলোড ব্যর্থ | `setup`/নতুন কোড Deploy করে Drive অনুমতি **Allow** করেছেন কি? ছবি ১২ MB এর নিচে? |
| ছবি দেখা যাচ্ছে না | Drive ফাইল "লিংক পাওয়া যে কেউ দেখতে পারবে" (আপলোডে নিজে হয়); লিংক `https://` কিনা |
| ইমেইল/SMS যাচ্ছে না | অ্যাডমিন → নোটিফিকেশনে "টেস্ট" চাপুন, ত্রুটির বার্তা দেখুন; Apps Script → Executions |
| GitHub Pages এ ৪০৪ | Settings → Pages এ branch/root ঠিক? `index.html` রুটে আছে? ২ মিনিট অপেক্ষা |
| সাইটে পুরনো রূপ | Ctrl+F5; সার্ভিস ওয়ার্কার ক্যাশ: DevTools → Application → Clear storage |

**রং বদলাতে:** `style.css` এর শুরুর `:root { --green … --gold … }` বদলান; ফাঁক/গোলাকার কোণও ওখানেই (`--sp-*`, `--r-*`)।
